Project purpose

This website presents research on Hypertext Transfer Protocol for IT 3203 Introduction to Web Development in Fall 2026. It adapts my Assignment 1 presentation into linked informational pages.

The research explains how browsers and servers exchange messages and how HTTP versions address connection and delivery limitations. Comparing TCP-based HTTP/2 with QUIC-based HTTP/3 extends the discussion beyond basic HTML and CSS.

Website implementation

The site consists of six HTML pages, one shared CSS file, and an original SVG illustration. Semantic headings, navigation, lists, and tables organize the content. CSS Grid and Flexbox handle the layout, and the navigation identifies the current page.

This is an educational class project. It is not an official KSU publication. Visit the IT 3203 course website for course information.
