Research references

These sources carry forward the reference numbering from my Assignment 1 report. Historical RFCs document earlier milestones; newer RFCs provide the updated specifications identified below.

  1. MDN Web Docs. Evolution of HTTP

    A readable overview of changes across HTTP versions.

  2. IETF. RFC 1945: Hypertext Transfer Protocol — HTTP/1.0 (1996)

    Historical documentation of HTTP/1.0.

  3. IETF. RFC 2068: Hypertext Transfer Protocol — HTTP/1.1 (1997)

    The original HTTP/1.1 specification; use newer RFCs for modern requirements.

  4. IETF. RFC 9110: HTTP Semantics (2022)

    Shared definitions for resources, methods, fields, and status codes.

  5. IETF. RFC 9111: HTTP Caching (2022)

    Rules for response storage, freshness, and validation.

  6. IETF. RFC 9112: HTTP/1.1 (2022)

    HTTP/1.1 message syntax, framing, and connection management.

  7. IETF. RFC 9113: HTTP/2 (2022)

    HTTP/2 streams, framing, and connection behavior.

  8. IETF. RFC 9114: HTTP/3 (2022)

    How HTTP maps onto QUIC.

  9. MDN Web Docs. Overview of HTTP

    A beginner-friendly explanation of HTTP’s architecture.

  10. IETF. RFC 6265: HTTP State Management Mechanism (2011)

    The cookie mechanism and its attributes.

  11. IETF HTTP Working Group. Active documents

    Further reading on working-group activity; drafts are not finished standards.

  12. IETF. RFC 7540: Hypertext Transfer Protocol Version 2 (2015)

    Historical HTTP/2 specification, superseded by RFC 9113.

Recommended learning path

  • Begin with MDN’s HTTP overview for an accessible introduction.
  • Read MDN’s evolution guide alongside the version comparison.
  • Consult RFC 9110 when you need a precise definition of a method or status.
  • Practice inspecting requests using the Network panel exercise.
